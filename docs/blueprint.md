# **App Name**: UAlright

## Core Features:

- User Authentication & Profile Management: Secure user authentication (email/password/social), onboarding, and management of personal profile, trusted contacts, and core safety settings.
- Loud Alarm Trigger: Activates an immediate, on-device audible alarm for deterrence and securely logs the incident within the user's history.
- Silent Alarm Escalation: Discreetly triggers background services to send personalized SMS alerts with real-time location and context to trusted contacts, including delivery status tracking.
- Staged Call Manager: Enables users to configure, store, and initiate pre-defined staged call scenarios, including custom audio assets and timed script cues for social cover.
- Duress Passcode Activation: Provides a discreet method to appear to disable an alarm while secretly triggering heightened escalation protocols, safeguarding the user in duress.
- Real-time Incident Monitoring: Presents a dynamic dashboard displaying critical updates for active incidents, such as location breadcrumbs, SMS delivery confirmations, and options to resolve the event.
- AI Script Co-pilot for Staged Calls: A generative AI tool that suggests contextual and emotionally resonant timed script cues for various staged call scenarios, enhancing realism and effectiveness.

## Style Guidelines:

- Primary color: A thoughtful, muted indigo-blue (#455B81). This hue evokes trust and stability, aligning with security, while offering a deep, substantive visual anchor.
- Background color: A very subtle, pale blue-grey (#F4F6F9). This choice ensures a clean backdrop that guides user focus onto critical information, creating a serene environment.
- Accent color: A soft, approachable lavender-purple (#A38FEF). This contrasting tone adds a touch of emotional intelligence and calm vitality, effectively highlighting key interactions without overwhelming the user.
- Body and headline font: 'PT Sans' (humanist sans-serif). Selected for its optimal readability, modern aesthetic, and inherent warmth, supporting the app's role as a trusted companion while maintaining critical clarity.
- Emphasize clean, minimalist line icons. Prioritize instant recognition for all alarm states, communication methods, and contact management functions to ensure intuitive use during urgent situations.
- Adopt an action-oriented design, ensuring prominent and immediate access to core safety features. Implement a clear, hierarchical organization of information, optimizing for rapid scanning, especially during incidents, with a mobile-first responsive approach.
- Employ subtle feedback animations for critical actions like alarm activation or message confirmations, coupled with smooth, non-disruptive screen transitions. This ensures a responsive and polished user experience without introducing any perceived delays during urgent operations.
